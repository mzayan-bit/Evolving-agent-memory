# Native CUPMem integration decision — 2026-09-26

**Keep as an external component reproduction; do not add a nominal native G1 arm.** Prior source/store checks are preserved in `COMPETITOR_REPRODUCTION.md` and `reproduction/`. Official STALE/CUPMem checkout: icedreamc/STALE, commit ea7d391103a151927cd29d2f01d87597a782bdcb. The successful smoke exercised unmodified store transitions, not the end-to-end model pipeline or reported scores. No new native model run occurred in this phase.

CUPMem's profile buckets, session deltas, conflict/invalidation lanes, judge prompts and native session/query task form the method. G1's fixed proposition records, AND/OR support sets, arbitrary source lineage and two historical truth views are not a lossless encoding of that interface. Flattening a conjunctive support into profile slots would alter semantics; calling our B5 schema a CUPMem adapter would replace the method's inference and evaluation. Neither is scientifically faithful.

A future native side experiment can run CUPMem on its original profile-update task with its own metrics, source licenses and model settings, followed by a separately reviewed translation study. Do not rank those native scores against G1 SDRR. A direct adapter requires a written bidirectional mapping, supported/unsupported case inventory, unchanged native prompts/store behavior, and dual native/G1 outcome validation. None is asserted here. This decision resolves inclusion for the candidate matrix, not published performance.

Rollback remains the prior audited paper with no attributable adaptable official code located in that audit (arXiv 2608.10502v1). No claim that code can never become available. B3 represents known-lineage descendant invalidation; B9 adds visible point-support rescue. They do not replay original tools, regenerate claim text or reproduce Rollback's answer-relevant execution algorithm. Complete-lineage variants use the existing explicit oracle flag and are reported in separate oracle tables. Both analogues remain useful internal threats, with limited fidelity stated rather than borrowing the paper's name.
