# Residual headroom protocol — prospective only

No proposed uncertainty-aware method is authorized by fixture behavior. First obtain independently adjudicated human gold, acceptable agreement, a signed development/evaluation separation and a baseline/resource/prompt freeze. Then run strong baselines, including B4b, B5b with classical closure, credible incremental replay, B9 and query-only B10, with both backbones and matched evidence/resources. Missing baseline executions and infrastructure failures remain visible; do not infer headroom from them.

## Estimands and evidence sequence

Use the existing scenario/source-family macro unit, stale dependent reuse rate (SDRR), false invalidation (FIR), nonavailability/coverage, current and historical answers, recurrence and actual resource vectors. Preserve denominators and ambiguous strata. Paired family differences, whole-family bootstrap intervals, raw family plots and leave-one-family-out analysis precede any novelty decision. No query-level pseudo-replication. Matched and unrestricted regimes are distinct.

1. Establish remaining error in the strongest admissible non-oracle baseline under real model inference. Examine both error and preservation; deleting/quarantining everything is not success.
2. Decompose residual errors using the existing taxonomy and separate information-access oracles. Require evidence that uncertainty in lineage/support matters, rather than ordinary bad text parsing, scope omissions, fixed-point bugs or insufficient tokens.
3. Hold inferred point proposals fixed across deterministic policies. If support-set representation or a development-fixed threshold removes the gap, stop method development. If a stronger backbone removes it, restrict or abandon the general claim.
4. Run competent incremental/full recomputation with the same accessible evidence and realistic regeneration costs. Compare cold setup and repeated-revision amortization. A symbolic replay-step count is not a model-cost result.
5. Vary a predeclared query/revision horizon to compare B10's cumulative verification/latency, answer correctness, untouched stale storage and later unaudited reuse. Persistence is justified only by measured outcomes beyond a corrected immediate answer.
6. Only proceed to a separately authorized method phase if practically meaningful residual harm persists across independently adjudicated families, is attributable to uncertain support, survives the above threats and is plausibly addressable without extra hidden information/resources.

## Quantitative decision rule without invented evidence

The earlier candidate 5 percentage-point SDRR margin and 2 pp guardrails remain **provisional human-review choices**, not empirically justified cutoffs. Do not promote them to acceptance thresholds here. Before any comparative human-study results, stakeholders must approve practical harm and preservation margins, resource ceilings, query horizons, allowed ambiguity and precision requirements. Predeclare baseline selection/multiplicity handling; report all serious candidates instead of cherry-picking a weak reference. Estimate residual harm and its uncertainty against those approved margins. Wide intervals mean inconclusive, not headroom or equivalence. Adapt sample size only by the existing variance/cost/feasibility rule, not favorable observed effects.

A qualitative gate requires independently reviewed error dossiers with visible source prefixes, point proposals, alternative supports, actual actions and oracle interventions. Distinguish missing evidence from unknown ancestry and genuinely correlated origins. Counterexamples authored for this repository cannot establish prevalence. Keep annotation disagreement intact.

If cached replay, classical maintenance, thresholded support inference or query audit meets the approved quality/resource requirements, record that G1 needs no new controller. If the only proposed novelty is confidence instead of a threshold, demand decision-relevant evidence beyond ordinary classification calibration; otherwise stop. Current evidence cannot answer whether enough residual headroom exists. **Method implementation decision: NO.**
