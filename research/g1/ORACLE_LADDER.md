# Oracle ladder — controlled interventions, not deployable competitors

The ladder is a factorial diagnostic design, not a guarantee that every successive row improves performance. Keep model, probes, common evidence realization and caps fixed; report unrestricted checks separately. Never pool these runs with main arms. Oracles see only the current prefix, not future revisions or answers.

| Condition | Privilege | Held fixed / comparison | What a gap can diagnose | Implemented? |
|---|---|---|---|---|
| O0 observed | None: source-change cue is an observation, not gold fault diagnosis | Main policy-isolation condition | Combined pipeline loss | Yes, finite-rule fixtures |
| O1 fault | Gold diagnosed faulty source IDs only; no affected descendant IDs | Same observed supports/policy | Fault discovery contribution, conditional on downstream interactions | Existing flag maps old changed version to fault for fixtures only; real diagnosis needs a separate gold fault field |
| O2 dependency graph | Correct prefix parent incidences, grouping/type hidden | Same B3/B5 graph action rule | Incidence inference loss; cannot rescue graph representation loss | Select B3 plus gold dependency bundle; only graph incidence is used. A strictly stripped graph projection is required before general adapters |
| O3 support sets | Gold sufficient groups, relation type, scoped/time predicates; origin truth only if separately declared | Same point B7, evidence and cap | AND/OR/type/origin representation contribution | Gold-support flag supplies bundle to B7; cannot be labelled non-oracle |
| O4 complete history | Complete available past source texts/versions, including otherwise hidden records; no future or answer gold | O3 plus same common verifier/reader, cost actual increased input | Source access/retrieval bottleneck | Protocol only; full_history flag merely exposes stored snapshots, NOT gold complete history |
| O5 replay ceiling | O4 plus correct executable domain rules and unrestricted deterministic recomputation | Common fixed queries and archive | Representation/scorer consistency | B2 fixtures approximate this only; natural-language replay can still err |

O5 full replay is an algorithm, not inherently an oracle. B2 under ordinary observed evidence belongs in the main comparison; the extra source/rule privileges define this ceiling. Likewise O2 cannot be mistaken for O3: the same pairwise edges can encode both AND and OR. Gold supports do not identify true answers without source admissibility and time/scope reasoning.

For an answerer ceiling, report deterministic structured readout separately from free-text generation; do not pass gold expected answers into a policy and call it improved repair. Prespecify paired replacements one component at a time. If a replacement changes both evidence and resources, the gap is confounded and must be labeled accordingly. Unknown gold cannot be upgraded to certain oracle truth.
