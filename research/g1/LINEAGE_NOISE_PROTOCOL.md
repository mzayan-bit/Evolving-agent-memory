# Lineage noise protocol candidate

Intervene on observed proposals only; keep source text, evaluator gold, fixed queries and seeds paired across policies. True unit is `(member, justification, target)` incidence. Denominator for spurious rate is original true incidences; also report visible precision, retained recall and exact masks. Unknown gold is not a known false-link pool. No naturalistic prevalence claim comes from balanced stress construction.

| Family | Operation | Matched comparison / annotation requirement |
|---|---|---|
| Random omission | Sample true incidences without replacement | Missing-only versus unchanged proposal; publish achieved counts on tiny graphs |
| Random insertion | Sample adjudicated false incidence candidates | Spurious-only; distinguish extra AND member from a new OR justification |
| Systematic omission | Drop an implicit prerequisite, distant cross-session link, or qualification lost in a summary | Human-marked eligible mechanisms; match removed count to random omission, not different overall severity |
| Semantic false positive | Attach same-topic but non-supporting belief | Adjudicated association/non-entailment; match entity/time and text length controls |
| Correlation error | Mark a copied/common-origin justification independent or omit its ancestry | Preserve observations; independently annotate origins and genuine ambiguity; do not just add an ordinary edge |
| Scope error | Move a valid relation to wrong entity/environment/version | Both source and destination IDs exist; exact scope predicates and unchanged bystander recorded |
| Temporal error | Apply expired/past support now or mistake correction for supersession | Valid-time versus recorded-time labels; history probes mandatory |
| Natural inference error | Freeze a model's observed support proposal before policy comparison | Human comparison to gold; no synthetic masks implied, report naturally realized error rates |

Development severity grid candidate: true-incidence retention {1,.9,.7,.5}, false/true incidence {0,.1,.3}; NOT all cells in the pilot. Select the primary stress pair on development interpretability and feasible budgets, not future winner separation. Historical .7/.3 is a stress anchor, not an empirically measured deployment rate. Pilot starts unchanged inferred proposal versus one prespecified combined stress; separate missing/spurious curves are expansion conditions and cannot be causally inferred from the combined contrast.

Use identical frozen inference A/B proposals crossed with decision policies B5/B7 and future methods. A clean model proposal means no added perturbation, not perfect gold lineage. Complete gold support is O3 and always separate. Systematic and natural-error conditions are mandatory before claiming a general method effect; random dropout alone supports only controlled sensitivity analysis.

Mask generation is coordinator/evaluator-only, versioned and seeded before runs. Predeclare candidate pools and deterministic tie rounding, prohibit selecting masks by observed policy performance. Unknown relationships remain an uncertainty stratum. Existing code implements random deletion, explicit spurious insertion, one type change and metadata/cue hiding; systematic/correlation/scope/temporal generators are designed here, not silently claimed implemented.
