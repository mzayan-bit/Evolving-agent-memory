# Eventual public artifact checklist

Status as of 2026-09-25; checkboxes are release gates, not completion claims.

- [x] Baseline source, deterministic fixtures, typed tests and dependency lock exist.
- [x] Baseline fidelity/deviation audit, separate controls/task/adjacent classes and candidate protocol exist.
- [x] Pinned external component commands, local environment and measured logs recorded; no vendored competitor repositories or weights.
- [x] Blank human packets remain preserved; their tests verify original draft copies.
- [ ] Independent human agreement, qualitative review and adjudication provenance.
- [ ] Licensed adjudicated data, source provenance, permitted redistribution and signed split/cluster manifest.
- [ ] Exact frozen main commit, clean-tree check, configs and cryptographic hashes for scenarios/probes/masks.
- [ ] Model-backed baselines/adapters with authoritative pins, prompt fidelity and documented deviations.
- [ ] Shared initial construction/inference artifacts plus their costs; no gold-runtime leakage.
- [ ] Prompt templates, schema retries, truncation, decoding/reasoning settings, cache policy and timeouts.
- [ ] API model IDs, access dates, request metadata, provider price snapshot; local weights/tokenizer/runtime hashes, precision/device details.
- [ ] Physical-call reservation/reconciliation, model-credit release schedule and monetary stop enforcement validated.
- [ ] Every raw attempt manifest, usage/response records (privacy redacted), failure logs, seeds, nondeterminism statement and artifact hashes.
- [ ] Scenario-cluster statistical scripts and unit tests, fixed planned contrast family and bootstrap seed.
- [ ] Figure/table-generation scripts reading frozen artifacts, including unfavorable conditions and NA denominators.
- [ ] Readable environment lock/container instructions, fresh-machine smoke, hardware/runtime report and approximate reproduction cost.
- [ ] Third-party licenses and notices; do not infer dataset redistribution rights from a code license or arXiv paper license.
- [ ] Independent artifact reviewer can regenerate all numbers and distinguish engineering fixtures from pilot observations.

Use a release manifest linking each table cell to run IDs/config/commit and each scenario to source/adjudication/split records. Store large or sensitive data in an appropriately licensed archive with checksums; never commit credentials or private participant data. Publish allowed labels and residual disagreements, not just consensus. External absence claims include search date, queries and authoritative pages checked. A paper's assertion that code is released is not a verified downloadable artifact.
