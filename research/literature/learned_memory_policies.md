# Learned memory management: what is already covered

“Learned” here means fitted policy/model parameters or explicit online statistical learning. An LLM making a prompted choice is not automatically an RL-trained memory policy; verbal reflection is not gradient-based RL. These are reported mechanisms, not reproduced results. Links point to the inspected primary work.

## Answer to the integrated-policy question

Yes: unified learned memory management is already studied. AgeMem and VerMem directly refute a broad claim of first unified LTM/STM control; Memory-R1 and Mem-alpha refute first learned write/update/delete; MemCon refutes the assumption that lifecycle policy learning must require large-scale RL. No reviewed result justifies asserting that a single policy has already achieved calibrated validity, complete semantic dependency repair, bounded total history storage and reliable external-world freshness across unrestricted deployments. That conjunction is **not automatically a publishable gap**: it is too broad until narrowed to a controlled hypothesis.

For the proposed project, begin with inference-only policies and a small fitted classifier. Reproducing Mem-alpha training is a poor first use of limited resources. Compare against simple deterministic revision, abstention and bandit policies before investing in a trained LM controller.
