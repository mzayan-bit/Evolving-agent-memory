# Citation

**Memory-R1: Enhancing Large Language Model Agents to Manage and Utilize Memories via Reinforcement Learning**. Yan, Sikuan; Yang, Xiufeng; Huang, Zuchao; Nie, Ercong; Ding, Zifeng; Li, Zonggen; Ma, Xiaowen; Bi, Jinhe; Kersting, Kristian; Pan, Jeff Z.; Schütze, Hinrich; Tresp, Volker; Ma, Yunpu. First public: 2025-08-27; arXiv preprint; no publication venue independently verified. [Reviewed primary version](https://arxiv.org/abs/2508.19828v5); v5 (2026-01-14).

Evidence level: targeted deep reading of method, evaluation and relevant limitations/appendices; no independent experimental reproduction. Author reports are distinguished below from reviewer inferences.

## Research Problem

Learn memory management and use from downstream feedback

## Why This Paper Exists

The design targets a concrete weakness in how prior agents evaluate or use memory. Learn memory management and use from downstream feedback. Its scope matters because learned crud already exists; semantic guarantees remain unestablished.

## Method

Train a memory manager over ADD/UPDATE/DELETE/NOOP and an answer agent that distills candidate memories for answering. PPO/GRPO optimize downstream answer feedback rather than hand-specified importance alone.

## Memory Lifecycle Covered

- **Write:** RL ADD/NOOP
- **Retrieve:** Retrieve candidates, then learned answer-time distillation
- **Update:** RL UPDATE
- **Consolidate:** Answer-time distillation; persistent generalized consolidation not established
- **Invalidate:** DELETE, without typed validity contract
- **Forget:** RL DELETE

## Representation

Managed textual memories

## Controller / Decision Policy

RL manager and answer agent. Appendix D reports four H100 80GB GPUs; 14B configuration uses eight. API-only replication of behavior is cheaper but is not reproducing training.

## Datasets

LoCoMo: 152 training, 81 validation and 1,307 test questions in reported split; zero-shot MSC and LongMemEval.

## Baselines

Prompted manager/answerer and memory-system comparisons across 3B/7B/8B/14B configurations.

## Metrics

QA exact/F1-style and judged metrics as specified per dataset.

## Main Findings

Small downstream training sets can train memory operations and use. This decisively invalidates a broad first-RL-memory-manager claim.

## Ablations

Manager, answer agent, distillation and PPO/GRPO comparisons.

## What It Actually Solves

Learn memory management and use from downstream feedback. The empirical support is restricted to the tasks and controls described above.

## What It Does NOT Solve

Learned CRUD already exists; semantic guarantees remain unestablished. This is a scope assessment, not a claim that the approach could never be extended.

## Author-Stated Limitations

Separate training and dialogue-centered scope limit broader agentic claims.

## Additional Limitations We Observe

Question-level split sizes do not themselves demonstrate persona/history-disjoint generalization. Candidate retrieval coverage is a separate bottleneck. Reward does not certify contradiction or temporal correctness.

## Relationship to Other Papers

Mem-alpha learns construction; AgeMem unifies context and persistent memory; TRUSTMEM adds transition feedback.

## Relevance to EvoMem

A required counterexample/baseline when considering learn memory management and use from downstream feedback. Any proposal must state its additional assumption, test and advantage over this work.
