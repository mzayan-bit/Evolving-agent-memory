# Citation

**When Memory Updates but Behavior Does Not: Repairing Implicit Stale Dependencies in Personalized Agent Responses**. Sun, Haofei; He, Lin. First public: 2026-08-03; arXiv preprint; no publication venue independently verified. [Reviewed primary version](https://arxiv.org/abs/2608.01619v1); v1 (2026-08-03).

Evidence level: targeted deep reading of method, evaluation and relevant limitations/appendices; no independent experimental reproduction. Author reports are distinguished below from reviewer inferences.

## Research Problem

Repair responses that implicitly rely on superseded state

## Why This Paper Exists

The design targets a concrete weakness in how prior agents evaluate or use memory. Repair responses that implicitly rely on superseded state. Its scope matters because time verification does not verify semantic supersession.

## Method

Use state-anchored evidence queries to expose unstated stale premises, audit a draft as valid/stale/unknown, then repair it. An LLM proposes old/new transitions; deterministic checks pin quotations to entries and check chronological order.

## Memory Lifecycle Covered

- **Write:** Uses an existing structured store
- **Retrieve:** State-anchored evidence retrieval
- **Update:** Repair answer behavior after state change
- **Consolidate:** Not a persistent consolidation policy
- **Invalidate:** Invalidate response premises using candidate transitions
- **Forget:** No comprehensive physical/store deletion

## Representation

State-anchored evidence transitions

## Controller / Decision Policy

LLM premise audit plus quote/time gate. 600-example QLoRA of a 4B model on an 8GB GPU is reported; inference variants use API calls.

## Datasets

STALE-derived tests, HorizonBench preference evolution and a harder authored lifecycle set; strict independent-query and joint-scenario scopes are distinguished.

## Baselines

Draft-only audit, state-aware audit and matched-budget evidence controls.

## Metrics

Current-state accuracy, false invalidation, candidate-gate acceptance and human agreement checks.

## Main Findings

Strict setting reports 0.736 versus 0.692 for a matched-budget control. Stronger joint-scenario numbers have extra information. Harder cross-family lifecycle tests show no accuracy gain, bounding the conclusion.

## Ablations

Audit anchoring, transition gate, semantic checks and matched retrieval budget; some controls preserve accuracy while reducing overcorrection.

## What It Actually Solves

Repair responses that implicitly rely on superseded state. The empirical support is restricted to the tasks and controls described above.

## What It Does NOT Solve

Time verification does not verify semantic supersession. This is a scope assessment, not a claim that the approach could never be extended.

## Author-Stated Limitations

Small/single-run studies, judge-family dependence and limited external coverage.

## Additional Limitations We Observe

An 80%-token quotation match and newer date verify provenance/order, not semantic supersession. The gate accepts semantically non-superseding transitions in a control, so calibrated semantic repair remains unresolved.

## Relationship to Other Papers
