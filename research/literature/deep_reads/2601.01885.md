# Citation

**Agentic Memory: Learning Unified Long-Term and Short-Term Memory Management for Large Language Model Agents**. Yu, Yi; Yao, Liuyi; Xie, Yuexiang; Tan, Qingquan; Feng, Jiaqi; Li, Yaliang; Wu, Libing. First public: 2026-01-05; ACL 2026 SAC Highlight; independently indexed. [Reviewed primary version](https://arxiv.org/abs/2601.01885v3); v3 (2026-07-23).

Evidence level: targeted deep reading of method, evaluation and relevant limitations/appendices; no independent experimental reproduction. Author reports are distinguished below from reviewer inferences.

## Research Problem

Learn unified long-term and short-term memory control

## Why This Paper Exists

The design targets a concrete weakness in how prior agents evaluate or use memory. Learn unified long-term and short-term memory control. Its scope matters because evaluation does not establish lifelong production-user reliability.

## Method

One policy controls persistent memory and active context using ADD, UPDATE, DELETE, RETRIEVE, SUMMARY and FILTER. A three-phase RL curriculum trains long-term construction, short-term management and joint use. Terminal task/context/memory rewards are propagated to decisions.

## Memory Lifecycle Covered

- **Write:** ADD
- **Retrieve:** RETRIEVE
- **Update:** UPDATE
- **Consolidate:** SUMMARY of active context
- **Invalidate:** DELETE can remove entries; epistemic semantics not guaranteed
- **Forget:** DELETE and FILTER

## Representation

Persistent store and active context

## Controller / Decision Policy

One RL policy with six operations. RL fine-tuning of 4B/7B models; exact total GPU-hours not established in this extraction. Treat reproduction as heavier than API baselines.

## Datasets

ALFWorld, ScienceWorld, PDDL, BabyAI and HotpotQA; HotpotQA-based training curriculum.

## Baselines

Memory and context-management agents compared under Qwen2.5-7B and Qwen3-4B settings.

## Metrics

Task success/accuracy, context and memory rewards, operation behavior.

## Main Findings

Unified learned lifecycle control already exists. Reported mean scores 41.96 and 54.31 exceed strongest compared baselines by 4.82 and 8.57 points in the respective backbone settings.

## Ablations

Long-term versus short-term control, RL removal, curriculum and reward components.

## What It Actually Solves

Learn unified long-term and short-term memory control. The empirical support is restricted to the tasks and controls described above.

## What It Does NOT Solve

Evaluation does not establish lifelong production-user reliability. This is a scope assessment, not a claim that the approach could never be extended.

## Author-Stated Limitations

Persistent real-user/lifelong deployment remains a future evaluation setting.

## Additional Limitations We Observe

Optimizing terminal task success can reward harmful memory shortcuts not exposed by the task. CRUD plus summarization is not a demonstrated safe supersession/rollback policy.

## Relationship to Other Papers

Memory-R1 separates agents; VerMem adds local/global verifiers; MemCon offers lightweight control.

## Relevance to EvoMem

A required counterexample/baseline when considering learn unified long-term and short-term memory control. Any proposal must state its additional assumption, test and advantage over this work.
