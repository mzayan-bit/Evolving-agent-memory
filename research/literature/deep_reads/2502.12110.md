# Citation

**A-MEM: Agentic Memory for LLM Agents**. Xu, Wujiang; Liang, Zujie; Mei, Kai; Gao, Hang; Tan, Juntao; Zhang, Yongfeng. First public: 2025-02-17; Author-reported status: Advances in Neural Information Processing Systems (NeurIPS 2025). [Reviewed primary version](https://arxiv.org/abs/2502.12110v11); v11 (2025-10-08).

Evidence level: targeted deep reading of method, evaluation and relevant limitations/appendices; no independent experimental reproduction. Author reports are distinguished below from reviewer inferences.

## Research Problem

Organize notes and evolve their contextual links

## Why This Paper Exists

The design targets a concrete weakness in how prior agents evaluate or use memory. Organize notes and evolve their contextual links. Its scope matters because associative links are not entailment dependencies.

## Method

Create a note with content, timestamp, keywords, tags, contextual description and links. Retrieve nearby notes and ask an LLM to establish links and revise their contextual descriptions. Query-time dense retrieval returns an augmented memory neighborhood.

## Memory Lifecycle Covered

- **Write:** LLM constructs structured notes
- **Retrieve:** Cosine similarity and linked context
- **Update:** Revise neighboring note metadata/context
- **Consolidate:** Contextual note evolution
- **Invalidate:** No explicit general invalidation semantics established
- **Forget:** No explicit selective deletion result established

## Representation

Zettelkasten-like text notes and links

## Controller / Decision Policy

LLM links/evolution and dense retrieval. Frozen/API LLM calls for writing and evolution; dense indexing. Per-update cost grows with selected neighborhood.

## Datasets

LoCoMo and DialSim; settings span several backbone models and retrieval counts.

## Baselines

Long-context and memory/retrieval systems listed in S4.

## Metrics

QA F1/BLEU and reported efficiency/scaling measurements.

## Main Findings

Linked note evolution can improve memory use in the tested dialogue tasks. It supplies a strong baseline for an adaptive graph memory, but links express association rather than a verified entailment relation.

## Ablations

Remove link generation and memory evolution; examine retrieval count and memory-size scaling.

## What It Actually Solves

Organize notes and evolve their contextual links. The empirical support is restricted to the tasks and controls described above.

## What It Does NOT Solve

Associative links are not entailment dependencies. This is a scope assessment, not a claim that the approach could never be extended.

## Author-Stated Limitations

Text-focused setting and dependence on LLM quality are discussed in S6.

## Additional Limitations We Observe

Rewriting neighboring context may spread an incorrect inference. There is no demonstrated invariant that updates retract precisely the logically dependent notes while preserving independent support.

## Relationship to Other Papers

HippoRAG models associative retrieval; StateMem and rollback repair use more explicit dependencies.

## Relevance to EvoMem

A required counterexample/baseline when considering organize notes and evolve their contextual links. Any proposal must state its additional assumption, test and advantage over this work.
