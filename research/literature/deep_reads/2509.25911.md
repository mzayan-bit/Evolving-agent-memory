# Citation

**Mem-{\alpha}: Learning Memory Construction via Reinforcement Learning**. Wang, Yu; Takanobu, Ryuichi; Liang, Zhiqi; Mao, Yuzhen; Hu, Yuanzhe; McAuley, Julian; Wu, Xiaojian. First public: 2025-09-30; arXiv preprint; no publication venue independently verified. [Reviewed primary version](https://arxiv.org/abs/2509.25911v1); v1 (2025-09-30).

Evidence level: targeted deep reading of method, evaluation and relevant limitations/appendices; no independent experimental reproduction. Author reports are distinguished below from reviewer inferences.

## Research Problem

Train a policy to construct compact task-useful memory

## Why This Paper Exists

The design targets a concrete weakness in how prior agents evaluate or use memory. Train a policy to construct compact task-useful memory. Its scope matters because small model parameter count understates reported training cost.

## Method

A policy observes incoming information and its current core, semantic and episodic memory, then edits that state. Rewards combine task QA, formatting, compression and an LLM semantic assessment; retrieval is fixed rather than jointly learned.

## Memory Lifecycle Covered

- **Write:** Learned insert
- **Retrieve:** Fixed retrieval
- **Update:** Learned update
- **Consolidate:** Compression-oriented memory editing
- **Invalidate:** Deletion possible; no explicit full validity algebra
- **Forget:** Learned delete

## Representation

Core, semantic and episodic memory

## Controller / Decision Policy

RL memory editing with multiple rewards. Reported training: 32 H100 GPUs for about three days, 205 steps. Too expensive as the initial reproduction target for this project.

## Datasets

Eight sources, 4,139 training instances and reported validation/evaluation sets; MemoryAgentBench evaluation covers three capability families.

## Baselines

Prompted memory construction and memory-system baselines using the same study settings.

## Metrics

QA score, memory size/compression, format validity and semantic reward.

## Main Findings

Memory construction itself is trainable, including compression. It is incorrect to describe the reported MemoryAgentBench results as covering every conflict/selective-forgetting task.

## Ablations

Reward contributions and model/formatting behavior, including appendix results for an 8B configuration.

## What It Actually Solves

Train a policy to construct compact task-useful memory. The empirical support is restricted to the tasks and controls described above.

## What It Does NOT Solve

Small model parameter count understates reported training cost. This is a scope assessment, not a claim that the approach could never be extended.

## Author-Stated Limitations

Simulated task settings do not capture full production complexity.

## Additional Limitations We Observe

A 4B policy is not automatically a small-compute project: rollout and optimization dominate. Fixed retrieval isolates one component but does not solve jointly calibrated lifecycle control.

## Relationship to Other Papers

TRUSTMEM uses this construction setting with transition-level feedback; AgeMem targets joint memory/context control.

## Relevance to EvoMem

A required counterexample/baseline when considering train a policy to construct compact task-useful memory. Any proposal must state its additional assumption, test and advantage over this work.
